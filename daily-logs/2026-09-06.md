## 오늘 한 일 — 스튜디오 Fee 얼리버드 옵션

관리자 페이지에서 코스별로 **얼리버드 스튜디오 Fee + 마감일**을 설정하면,
마감일까지는 얼리버드 가격이, **다음 날 00:00(LA 기준)부터는 자동으로 정가**가
사이트·웰컴 이메일 양쪽에 반영되도록 구현했다. 별도 조작이 필요 없다.

### 규칙 (한 곳에서만 판정)
- 얼리버드 금액(`fee_early`)과 마감일(`early_until`)이 **둘 다** 있고
  `오늘(America/Los_Angeles) ≤ 마감일` → 얼리버드 가격, 아니면 정가(`fee`).
- 마감일은 **포함** — 예) `2026-10-01` → 10/1까지 얼리버드, **10/2부터 정가**.
- 시간대는 항상 스튜디오(LA) 기준. 한국에서 접속해도 같은 날짜로 보인다.

### 변경 파일
- `apps-script/google-apps-script.js`
  - Courses 탭 14열 → 16열 (`O: fee_early`, `P: early_until`). `upgradeCoursesTab` 실행 시 기존 시트에 자동 보충, P열은 텍스트 서식 고정.
  - 헬퍼 신설: `STUDIO_TIMEZONE`, `dateToString_`, `studioToday_`, `effectiveFee_`, `earlyUntilLabel_`, `courseIdsOf_`, `earlyFeeNotes_`.
  - 웰컴 이메일 Studio Fee 행: 얼리버드면 금액 + 정가 취소선 + `Early bird (through Oct 1)`, 지났으면 정가만.
  - 관리자 알림 메일: 얼리버드 적용 신청일 때만 "■ 얼리버드 적용 (신청 시각 기준)" 블록 추가 → 실제 청구 금액 확인용.
- `src/components/TrainingForm.tsx`: `fee_early`/`early_until` 수신, `studioToday()` + `effectiveFee()`로 **렌더 시점 계산**(localStorage 캐시가 남아 있어도 날짜가 지나면 정가로 전환), 카드에 취소선 + 얼리버드 한 줄.
- `src/i18n/translations.ts`: `earlyBird` EN `Early bird — through {date}` / KR `얼리버드 — {date}까지`.
- `public/admin/index.html`: 얼리버드 Fee + 마감일(`type="date"`) 입력, 입력 즉시 갱신되는 상태 문구 + 칩(`얼리버드 적용중 · D-25` / `얼리버드 종료 — 정가 적용중`), `스튜디오 Fee` → `스튜디오 Fee (정가)`.
- `apps-script/SETUP-KO.md`: 새 열 설명, 자동 전환 규칙, 관리 방법 문서화.
