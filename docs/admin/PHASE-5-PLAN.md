## 1. 출발점

| 필요한 것 | 지금 상태 | 이번 처리 |
|---|---|---|
| 학생 명단 (결제 대상 선택) | **없음.** 마스터 플랜의 4A(학생 원장)는 지도자 과정 신청만 옮기는 것으로 바뀌었고, 일반 수업 회원은 Mindbody에만 있다 | 최소 `students` 테이블을 만든다. 결제 화면에서 검색해서 없으면 그 자리에서 **새 학생 추가** (이름 + 전화 선택). 명단은 결제하면서 자연스럽게 쌓인다. Mindbody 고객 CSV 가져오기는 Students 화면이 생길 때 |
| 가격표 (금액 제안 칩) | 가격 미확정 (마스터 플랜 O-9) | **가격표 테이블 없음.** 대신 그 학생의 **지난 결제 금액·수단을 자동으로 채운다** (설정 0개, 반복 결제가 가장 흔한 경우) |
| 직원·역할·감사 로그 | 있음 (Phase 2) | 그대로 사용. STAFF = INSTRUCTOR 권한 |

## 2. 이번 단계에서 하는 것

### DB (마이그레이션 1개 `…_daily_income.sql`)
- `students` — 이름, 전화, 이메일, 상태. 강사·스태프는 **테이블을 직접 못 읽고** `search_students()`로 이름·전화 끝 4자리·마지막 결제일·지난 금액/수단만 받는다.
- `payment_methods` — Cash, Zelle, Venmo, Credit Card, Debit Card, Check, Other (시드).
- `payment_transactions` — 금액은 정수 센트, 영업일은 LA 날짜(트리거), 삭제 없음(무효 = `VOID`), `client_request_id`로 중복 제출 방지, 메모에 카드번호 형태 차단, $20,000 상한.
- `accounting_periods` — 월별 OPEN/CLOSED. 이번엔 마감 버튼이 없고(Phase 7), **마감된 달의 결제는 추가·수정이 막히는 트리거**만 먼저 둔다.
- 함수: `record_payment`, `correct_payment`, `void_payment`, `record_refund`(오너), `search_students`, `add_student`.
  - 기록자 = 로그인한 본인 (서버가 정함, 보내도 무시).
  - 강사·스태프 정정·무효: **본인 것 + 같은 LA 영업일 + 유효 상태**만. 오너: 열린 달의 모든 결제.
  - 같은 학생·같은 금액이 10분 안에 또 들어오면 경고 → "그래도 저장"일 때만 저장.
  - 환불: 원래 결제에 연결, 환불 합계 ≤ 원금, 오늘 날짜로 기록.
- 모든 변경은 기존 `audit_logs`에 전/후 기록.

### 화면 (`/admin/daily-income`, 모든 역할)
- **결제 입력** (폰 우선): 학생 검색 → 선택 → 금액·수단 자동 → 저장. 최근 결제 학생 목록, Walk-in, 새 학생 추가.
  저장 버튼에 "$250.00 · Zelle 받음 · 저장"처럼 금액과 수단을 보여 확인 없이 저장되는 실수를 줄인다.
- **내 이력** (강사·스태프): 본인 기록만, 날짜별 묶음, 오늘 합계. 같은 날 건은 정정·무효 가능.
- **거래 목록** (오너): 기간(오늘/이번 주/이번 달/지정) · 기록자 · 수단 · 상태 필터, 합계(매출·환불·순매출·건수), 정정·무효·환불.
- **대시보드 카드**: 오너 = 오늘 순매출과 건수, 강사·스태프 = 내 오늘 합계 (+ 결제 입력 바로가기).
- 사이드바에 "Daily Income / 일일 매출" 메뉴 추가.

## 3. 하지 않는 것 (다음 단계)

- 월 마감·재오픈·조정(ADJUSTMENT), 재무 리포트·CSV → Phase 7.
- 가격표·결제수단 설정 화면, Students 화면(병합·Mindbody CSV), walk-in을 학생에 연결 → 필요할 때.
- 공개 홈페이지 변경 없음.

## 4. 결정한 기본값 (바꾸고 싶으면 말씀 주세요)

1. 학생 명단은 결제 화면에서 바로 추가 (가져오기 없이 시작).
2. 금액 제안 = 그 학생의 지난 결제. 가격표 칩은 가격 확정 후.
3. 스태프는 강사와 같은 권한 (결제 입력 가능, 본인 것만 조회).
4. 강사 본인의 오늘 합계는 보여준다 (마스터 플랜 O-7 기본값).
5. 주 시작 = 월요일 (O-6 기본값).
